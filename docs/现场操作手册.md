# 现场操作手册

建议至少安排一名主持人和一名技术操作人员。技术人员操作控制台，主持人按约定口令引导台上和台下参与。

macOS 可双击项目根目录的 `启动.command` 开始，控制台会自动打开。首次生成的配置使用 `3188` 端口，主持口令显示在终端并保存在 `.env`；已有配置则沿用。活动期间保持终端运行，结束后按 `Control + C` 停止。`scripts/preview.mjs` 是仅供本机演示的隔离预览，不能作为现场手机入场服务。

## 活动前：完整彩排

1. 启动服务，在主持控制台登录，填写活动标题、副标题、启动文案、Logo、主题和倒计时秒数。
2. 打开大屏页面，将浏览器移至 LED 屏或投影对应显示器，并使用浏览器全屏。检查屏幕比例、中文换行、二维码尺寸和场内实际可扫码距离。
3. 添加演示头像，检查头像漂浮、人数、汇聚、倒计时和最终揭幕。演示嘉宾只用于测试，正式活动前清空场次。
4. 点击保留嘉宾的复位操作，检查再次启动；再执行清空场次，检查人数回零、旧场次资料不再显示。
5. 清空后使用新二维码，用两部真实手机入场。至少一部手机使用正式活动预计采用的网络方式。
6. 手机上传头像后确认大屏实时更新；手机刷新后检查是否仍能识别本人资料。另开大屏浏览器检查状态同步。
7. 演练一次断网恢复和刷新页面。如果活动要求声效，先点击大屏右下角“开启声效”并实测；也可按 `M` 切换。浏览器需要人工操作来允许播放声音。按 `F` 或点击“全屏 F”可切换全屏。
8. 最后再清空测试场次，将正式二维码展示在大屏或现场物料上。

**印刷或提前制作二维码前，先确定公网域名或固定电脑地址。** 清空场次会产生新的场次标识；正式发出的二维码应以最后一次清空后的控制台链接为准。

## 正式入场

主持人可引导：

> 请大家用微信扫描屏幕上的二维码，填写昵称并选择头像，确认后就能在大屏上看到自己。请保持页面打开，和我们一起见证启动时刻。

嘉宾在手机上填写昵称、选择头像并勾选展示同意后入场。未上传图片的嘉宾使用默认头像。系统不会从微信自动读取昵称或头像。

技术人员检查控制台人数持续变化、大屏连接正常，移除不适合展示的头像或昵称。手机端每 2 秒同步一次状态，大屏和控制台持续接收实时推送。当前版本没有入场前人工审核队列；如活动要求严格内容审核，应提前采用受控名单或扩展审核功能。

同一手机与浏览器会保存本人参与标识，用于修改资料和避免重复报名。更换手机、清除浏览器存储或使用另一个浏览器，可能被视为新的参与者。

## 启动时刻

1. 技术人员确认活动文案、Logo 和参与人数，检查大屏无断线提示。
2. 主持人按彩排节奏邀请嘉宾准备，现场工作人员确认摄影摄像已就绪。
3. 操作人员在控制台开始倒计时。**倒计时开始后，新嘉宾不能继续入场。**
4. 大屏按服务器时间显示倒计时，播放头像汇聚与启动揭幕效果。
5. 让最终活动主题在屏幕保留，便于合影和拍摄。

主持词示例：

> 此刻，大屏上的每一个头像，都代表一份共同的期待。让我们一起倒数，见证「活动名称」正式启动！

若要重演，使用保留嘉宾的复位操作，再按现场口令开始。复位会让所有连接页面回到等待状态，操作前与主持人协调。

## 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 手机扫不开二维码 | 检查二维码是否为手机可达的局域网或公网地址；手机不能访问电脑 `localhost`。酒店 Wi-Fi 可能启用设备隔离，改用已验证的网络。 |
| 微信能打开但头像传不上 | 重新选择常见 JPEG、PNG 或 WebP 图片；手机页会压缩图片。检查网络、文件是否损坏，以及场次是否已开始倒计时。 |
| 人数未实时增加 | 检查页面连接提示，等待重连；确认代理未缓存或缓冲 `/api/events`。必要时刷新大屏与控制台。 |
| 手机状态稍晚变化 | 手机每 2 秒刷新状态，存在短暂延迟属正常；持续不更新时检查网络并刷新页面。 |
| 大屏断网 | 保持当前页面，恢复网络后自动重连。进行正式启动前应先恢复控制台与大屏连接。 |
| 误点开始倒计时 | 及时使用保留嘉宾的复位操作；确认所有屏幕回到等待状态后重新开始。 |
| 旧二维码不能入场 | 检查是否清空过场次。重新展示控制台当前二维码，关闭手机旧页后再扫。 |
| 手机显示已经入场 | 可在本人页面修改资料；不必换浏览器重复加入。 |
| 主持口令忘记 | 由技术人员核对 `.env`；修改后重启服务并重新登录。不要将口令发到观众群。 |
| 服务重启 | 重新登录控制台并核对大屏阶段。倒计时以原服务器时间恢复，不会因为重启自动从头开始。未固定主持口令时，使用新一轮启动在终端显示的口令。 |
| 头像动画卡顿 | 关闭无关程序和多余大屏标签页，检查电脑与浏览器性能，降低参与规模或选用已彩排的设备。 |

## 收场

1. 若仍需合影，先保留最终大屏，拍摄完成后再清场。
2. 在控制台清空场次，确认参与者人数归零。
3. 停止服务，退出主持控制台，撤下入场二维码和活动链接。
4. 按与嘉宾约定的保留期限清理参与资料；检查人工备份、服务器快照、浏览器存储和此前导出的文件。详情见技术说明的数据部分。
5. 保存下一场可复用的活动配置时，避免连同本场嘉宾头像和昵称一起分发。
