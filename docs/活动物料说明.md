# Delta Space 活动物料接入说明

## 来源

本轮页面视觉依据主办方提供的两份活动物料调整，原始文件均未修改：

- 背景来源：主办方提供的 `底图.pdf`（原文件不随代码仓库发布）。
- 版式、标识和活动文案参考：主办方提供的 `电梯厅.png`（原文件不随代码仓库发布）。

当前网页的黑棕底色、左橙右蓝光影、纵向折页、白色窄体标题及星芒元素，应与这套物料保持一致。此前的印象派园区背景不再作为活动主视觉。

## PDF 检查结果

- 单页，页面尺寸为 4116.625 × 2812.685 pt。
- 由 Figma 导出，不含可提取文字或字体。
- 页面包含一个 1024 × 1365 像素的 JPEG 图像资源，配有裁剪与轻微旋转变换。底图本身没有活动文字或 Logo。
- 原嵌入图的上、下部为黑色留白；整页直接渲染还会出现左侧白色边缘。因此网页采用原嵌入图的有效可视区域，不把整页 PDF 直接作为背景。
- 原资源为栅格图像。SVG 文件只是把同一原 JPEG 放入准确视口，不代表增加了分辨率，也不是矢量重绘。

## 网页资源

| 文件 | 用途 | 规格 |
| --- | --- | --- |
| `public/assets/event/background.svg` | 推荐网页背景 | 内嵌原 JPEG 的自包含 SVG，约 55 KB，无外部资源、文字、白边与上、下留白 |
| `public/assets/event/background.jpg` | JPEG 兼容回退与预览 | 1024 × 691 像素，约 44 KB，与 SVG 有效视口一致 |
| `public/assets/event/background-image.jpg` | 保留 PDF 中的原 JPEG | 1024 × 1365 像素，约 41 KB，含原上、下黑色区域 |

网页可直接引用 `/assets/event/background.svg` 或 `/assets/event/background.jpg`。它们均来自主办方文件，未使用 AI 重新生成或改变光影内容。

有效视口为原嵌入图的 `x=0, y=336, width=1024, height=691`。SVG 使用 `viewBox="0 336 1024 691"` 裁定该区域；JPEG 回退为同一区域的文档资产提取结果。此处理仅移除原图边界之外的无效留白。

## 标识与文案边界

电梯厅参考图为 8200 × 5400 像素的完整海报，含 Delta Space 品牌标识、活动标题、签到字样、日期时间和地点。它适合作为布局、字形与色彩的视觉依据；整张海报不应直接铺到互动页面，否则会把签到、日期、地点等印刷信息与网页控件叠在一起。

PDF 中没有可分离的独立 Logo。不要将当前几何示意标记称为正式 Logo，也不要以手绘方式冒充品牌原标。如果需要精确复用海报顶部的小 Logo，应由主办方提供透明底或矢量版本；在取得该文件前，可以用清晰的 Delta Space 文字标识，或通过 CSS 对原始海报局部作可视裁剪。

海报中的核心活动表达为“DELTA SPACE 正式启动”“DELTA SPACE 启动日活动”，品牌主张为“让每个年轻人找到自己的增量△”。互动流程的按钮和提示应围绕扫码加入、共同启动和现场见证编写，不复制海报中的“签到处 CHECK IN”来代替主持操作说明。

## 检查方式

使用 `pdfinfo`、`pdftotext`、`pdffonts` 检查页面结构；使用 Poppler 渲染完整 PDF 进行视觉核对，再通过 `pypdf` 提取原 JPEG。已查看提取后的 JPEG 回退图，确认左橙右蓝纵向折页、黑棕背景均与提供的底图一致，且没有新增文字或图形。

中间渲染和完整页面导出保存在 `tmp/pdfs/`，不作为网站主资源。
